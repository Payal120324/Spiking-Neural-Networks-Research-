# Spike-Legal-NLP Research Framework

## A Semantic- and Energy-Aware Study of Spike Encoding for Legal Text Classification Under Domain Shift

**Author:** Payal Salve  
**Department of Computer Science, Ramnarain Ruia Autonomous College**

## Overview

**Spike-Legal-NLP** is a research framework for studying the use of **Spiking Neural Networks (SNNs)** for legal text classification.

The research investigates how dense embeddings generated by transformer-based legal language models can be converted into spike trains using different spike encoding strategies, and how these representations perform in terms of:

- Classification performance
- Semantic preservation
- Theoretical energy consumption
- Domain-shift robustness

The study evaluates five spike encoding strategies using **LegalBERT embeddings** and legal NLP datasets from the **LexGLUE** benchmark.

The research is presented in the paper:

> **A Semantic- and Energy-Aware Study of Spike Encoding for Legal Text Classification Under Domain Shift**

| **RQ3** | How robust are spike-based classifiers under domain shift? |
| **RQ4** | Does spike encoding provide measurable energy savings compared with transformer baselines? |

---

## Hypotheses

### H1 — Classification Performance

Spike encoding achieves competitive classification performance compared with transformer baselines.

### H2 — Semantic Preservation

Time-based spike encodings preserve legal semantics better than simple rate coding.

### H3 — Energy Efficiency

Energy improvements exist, but become smaller when memory access is included.

### H4 — Domain Shift

Domain shift affects different models differently.

Spike Encoding Methods

The framework evaluates five spike encoding strategies.

Encoding	Description
Poisson Rate	Represents embedding values through stochastic firing rates.
Latency	Encodes activation magnitude through spike timing.
Temporal	Quantizes embedding values into discrete temporal levels.
Population	Represents scalar values using multiple neurons with Gaussian receptive fields.
Adaptive Binary Threshold	Generates spikes using a percentile-based adaptive threshold.
SNN Classifier

The spike trains generated by the encoding methods are processed using a feed-forward Spiking Neural Network based on Leaky Integrate-and-Fire (LIF) neurons.

The classifier uses:

LIF neurons
Membrane decay
Firing threshold
Subtractive reset
Adam optimizer
Cosine learning-rate schedule

The same downstream classifier architecture is used across the encoding methods.

4. Domain-Shift Evaluation

The original domain-shift protocol attempted to train on CaseHOLD and evaluate on ECtHR datasets.

During the research, a label-space mismatch was identified. CaseHOLD uses candidate-index labels that do not correspond to the label taxonomy used by the ECtHR datasets.

Therefore, CaseHOLD could not provide a valid classification-level transfer experiment to ECtHR.

The protocol was revised to the label-compatible pair:

ECtHR-A → ECtHR-B

This is a zero-shot transfer evaluation without retraining on the target dataset.

Final Domain-Shift Results
Model	Accuracy Drop	Target Accuracy	H-Score
Transformer	-0.1722	0.5833	0.4823
SNN — Poisson Rate	-0.1767	0.5767	0.4724
SNN — Latency	-0.1722	0.5833	0.4823
SNN — Temporal	-0.1833	0.5833	0.4746
SNN — Population	-0.1833	0.5833	0.4746
SNN — Binary Threshold	-0.1789	0.5900	0.4846

The negative accuracy drops were not interpreted as evidence that spike encoding improves domain generalization. The target dataset has stronger class imbalance, which provides an explanation for the higher target accuracy.

Representation-Level Domain Shift

Because classification-level CaseHOLD → ECtHR transfer was not label-compatible, the study also evaluated domain shift using label-free embedding statistics.

Comparison	Centroid Distance	Cosine Similarity	MMD	Variance Ratio
CaseHOLD → ECtHR-A	8.2145	0.7873	0.1408	0.5276
CaseHOLD → ECtHR-B	8.2145	0.7873	0.1408	0.5276
ECtHR-A → ECtHR-B	~0.0000	~1.0000	~0.0000	1.0000

These measurements provide label-independent evidence of a representation-level difference between CaseHOLD and ECtHR.

Research Corrections

A major part of the research involved diagnosing and correcting issues in the experimental framework.

Classification Readout Bug

The original SNN readout discarded the continuous membrane-potential output and instead used a coarse spike-count sum.

This caused four of the five encodings to collapse toward an always-predict-one-class solution.

Normalization Defect

The original implementation used per-sample min-max normalization.

Two embedding dimensions dominated the per-sample extrema for approximately three-quarters of the samples.

The normalization was changed to global per-feature statistics fitted on the training split and applied consistently to the other splits.

PCA concentration in the affected representations decreased from approximately 94% to approximately 38% after the correction.

Population Encoding Memory Issue

The population encoding produced an out-of-memory failure during training because of its larger memory footprint.

The final corrected experiment used a batch size of 32.

Domain-Shift Label-Space Issue

CaseHOLD candidate-index labels did not correspond to the ECtHR label taxonomy.

The domain-shift evaluation was therefore changed to ECtHR-A → ECtHR-B.

Limitations

The study has several limitations:

Dataset sizes limit statistical power.
Energy values are theoretical estimates rather than physical hardware measurements.
Poisson-rate encoding is stochastic and can vary across runs.
The experiments use LegalBERT as the transformer backbone.
The corrected domain-shift classification experiment uses ECtHR-A and ECtHR-B.
The original CaseHOLD → ECtHR classification transfer could not be evaluated because of incompatible label spaces.
Hyperparameter values differ between some project documentation and runtime configuration records.
Some generated figures correspond to a different experimental run than the primary result tables.
Future Research

The research identifies the following directions:

Investigate the class-specific rank-sensitivity hypothesis.
Integrate an additional legal dataset with compatible labels and a genuinely distinct domain.
Reconcile the methodology document and runtime configuration into a single authoritative configuration.
Validate the theoretical energy analysis on physical neuromorphic hardware.
Perform multi-seed experiments, particularly for Poisson-rate encoding.
Evaluate additional legal-NLP transformer backbones and tasks.
